In the navigation bar, switch to the Multiplex to start a random walk.

Uploading a graph

First of all, you must upload your graph. Our program uses .ZIP archive to represent graphs. The .ZIP archive should contain :

  • A file named layer_name.tsv, with two columns, attributing to each layer index a name
  • A folder named multiplex containing
    • Numbered folders (start from 1) corresponding to the layers, each containing TSV files describing relations between nodes of that layer
  • A folder named bipartite containing files named according to the M_N.tsv pattern, where M and N are integers, describing relations between nodes of layer M et nodes of layer N.

When you are done uploading your archive, click >>> to continue.

Uploading wizard

If you don’t have a ZIP archive ready, you can use our uploading wizard by clicking on Generate Zip. We will guide you step by step into building a perfect archive.

Random walk settings

You must first select the layer in which the seed you wish to use is located. Then, click >>> to continue.

Wait a few seconds as all seeds in this layer are loaded from the graph.

You can now fill in the parameters to be used by the random walk algorithm.

  • Title: this is necessary so your results can be identified in the database.
  • User: enter a username which will also be saved in the database.
  • Steps: the number of steps (or iterations) the random walk algorithm will take inside the graph.
  • Top: the amount of nodes that will be shown in each layer in the interactive graph.
  • Restart
  • Seeds: the nodes that will be used as seeds for the random walk. The seed names, if there are more than one, should be separated by commas. You can use the grid view on the right side of the screen, as well as the search bar, to complete your selection. Your selection of seeds needs to be validated in the dialog that shows up on the top-left of the window.

Viewing the graph

If popup windows aren't allowed by your browser settings, the random walk results are still available in the Logs database. Otherwise, the interactive graph should display in a new tab.

Layers of the graph are shown as horizontal rectangles. Interactions within one layer are displayed as grey lines, while interactions between layers are color-coded. Nodes have a varying diameter depending on their random walk score.

Clicking on any type of interaction within the legend allows you to display or hide the edges of that type, to surface the information most relevant to you.

Hovering on any node will display an infotip containing the node’s name, layer, random walk score, and a list of all its neighbours.

Various zoom functions provided by Plotly are available in the toolbar. You can always double-click to reset the view.

Printing

You can use your browser's Print feature to print the graph as it is currently displayed, or export it to any program installed as a printer (such as a PDF converter).
